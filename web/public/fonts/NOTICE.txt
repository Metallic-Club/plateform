Fonts served by the Metallic website
====================================

These are the font files Metallic Studio bundles (Metallic-Club/studio,
crates/metallic_ui_theme/assets/fonts/), so every surface draws the same glyphs.
Studio ships them as TrueType; here each one is the same font, unchanged apart from
WOFF2 compression (fontTools, flavor "woff2"). The subsets are Studio's: Latin and
Latin Extended plus punctuation, currency, letterlike symbols and arrows; see the
NOTICE.txt next to Studio's copies for the exact ranges. The site loads them with
next/font/local in src/app/layout.tsx. Each font keeps its licence text next to it.

Archivo-Variable.woff2
  Archivo, Version 2.001, variable (wght 100-900, wdth 62-125).
  Copyright 2020 The Archivo Project Authors (https://github.com/Omnibus-Type/Archivo).
  SIL Open Font License 1.1, see OFL-Archivo.txt.
  Source: https://github.com/google/fonts/tree/main/ofl/archivo, file Archivo[wdth,wght].ttf.

JetBrainsMono-Variable.woff2
  JetBrains Mono, Version 2.304, variable (wght 100-800).
  Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono).
  SIL Open Font License 1.1, see OFL-JetBrainsMono.txt.
  Source: https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304,
  file fonts/variable/JetBrainsMono[wght].ttf.

NotoSans-Variable.woff2
  Noto Sans, Version 2.015, variable (wght 100-900; the wdth axis pinned at 100).
  Copyright 2022 The Noto Project Authors (https://github.com/notofonts/latin-greek-cyrillic).
  SIL Open Font License 1.1, see OFL-NotoSans.txt.
  Source: https://github.com/google/fonts/tree/main/ofl/notosans, file NotoSans[wdth,wght].ttf.
  Used only as the fallback for Greek and Cyrillic, which Archivo does not cover; the
  browser downloads it only when a page has such text (unicode-range).

To update: copy the .ttf files and OFL texts from Studio's fonts folder and convert each
.ttf with fontTools:
  python -c "import sys; from fontTools.ttLib import TTFont; f = TTFont(sys.argv[1]); f.flavor = 'woff2'; f.save(sys.argv[2])" IN.ttf OUT.woff2
(needs the fonttools and brotli packages).
