Provision a server

POST /v1/servers
curl -X POST https://api.metallic.dev/v1/servers \ -H "Authorization: Bearer $TOKEN" \ -H "Content-Type: application/json" \ -d '{ "game_id": "cyber-raven", "region": "us-east", "player_cap": 64, "resource_ceiling": { "cpu": 2, "memory_mb": 2048 } }'
{ "id": "srv_8f31c", "state": "provisioning", "player_cap": 64, "players": 0, "hard_limit": { "cpu": 2, "memory_mb": 2048 }, "ready_in_ms": 1800 }

Conventions

Read before shipping
Errors

RFC 9457 problem details with a stable code. No stack traces.

Ids

Prefixed and opaque: usr_, srv_, itm_.

Time

UTC ISO-8601. Counts are integers, never pre-formatted strings.
