# Instructions for Codex and other AI agents

This repo is worked on by several AI sessions in parallel. Follow `CLAUDE.md` in full: it is the working agreement for
every agent here, whatever the model (claim an issue, one branch/worktree/PR per issue, branches named
`platform/<issue#>-<slug>`, no pushes to `main`, no secrets or personal data, run the web, backend and API checks
before a PR, keep `docs/agents/<issue#>-<slug>.md` current). Start with `docs/STATUS.md` once it exists, then the spec
`docs/superpowers/specs/2026-10-30-platform-design.md` and the API contract `api/openapi.yaml`.
Where `CLAUDE.md` names a commit trailer, use the trailer for your own model instead of "Claude Opus 5.5".
