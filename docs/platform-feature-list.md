# Metallic Platform: owner's feature list (raw, 2026-10-30, last addition 2026-10-31)

Captured from the owner's message as written, grouped only for reading. Not a design yet: the platform gets its own
design pass after the Metallic Studio design is approved. Lines marked "reading:" are guesses to confirm with the owner.

## Main navigation (owner, 2026-10-30)
- Home, Explore, Wardrobe, Marketplace (reading: the top-level tabs of the site/launcher, in this order)

## Accounts and safety
- Secure login
- Profiles: edit bio; link Discord, YouTube, Twitch, TikTok and more
- Friends
- Good moderation
- Auto-deletion of unverified accounts: an account not verified within a month of creation is removed
  (reading: "verify" is the missing word; confirm what counts as verifying)
- Detection of many accounts from the same IP address (reading: owner wrote "ai address")
- Name sniping is not allowed
- Alts: 5 accounts per person (reading: owner wrote "minimum"; most likely a maximum of 5)
- A ban on one account bans all of that person's alts

## Scale
- Scalable; able to handle millions of users "just in case"
- Optimisation for scalability

## Discovery
